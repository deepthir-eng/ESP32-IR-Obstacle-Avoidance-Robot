IR Obstacle Avoidance Robot

An autonomous mobile robot that reads its environment through infrared sensors, steers itself around obstacles in real time, and reports its status to the cloud — all on a single ESP32.

01 Overview

The IoT-enabled autonomous obstacle detection robot is an embedded systems project powered by the ESP32 microcontroller and infrared sensors. It navigates environments independently while transmitting real-time operational data to a cloud dashboard.

The onboard ESP32 processes digital signals from IR sensors to make real-time steering decisions, while its built-in Wi-Fi publishes live sensor states for remote monitoring.

03 Working Principle

A 12V battery powers the L298N driver, which regulates power to the ESP32 and IR sensors. The sensors continuously scan for obstacles; on detection, the ESP32 commands the motor driver to steer around them — while streaming live status over Wi-Fi to a remote dashboard.

int IRSensor = 12;

void setup() {
  pinMode(IRSensor, INPUT);
  Serial.begin(115200);
}

void loop() {
  int sensorValue = digitalRead(IRSensor);

  if (sensorValue == HIGH) {
    Serial.println("Obstacle Detected!");
  } else {
    Serial.println("Path Clear");
  }
}
